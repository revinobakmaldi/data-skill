# Incident types

- `refresh-failure`
- `source-drift`
- `wrong-numbers`
- `access-or-rls`
- `performance-regression`
- `report-ux-defect`
- `binding-or-project-structure`

Failure-layer shortcuts:

- source issue -> upstream data / ingestion / schema drift
- model issue -> DAX, relationships, measures, naming, refresh semantics
- report issue -> visual config, PBIR, filters, bookmarks, themes
- access issue -> permissions, RLS, workspace/report access

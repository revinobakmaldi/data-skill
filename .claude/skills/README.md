# Project BI skills

These skills make the local BI subagents stronger than prompt-only markdown files.

They provide:
- workflow-specific instructions
- reusable templates
- deterministic checklists
- plugin-routing guidance for `pbip`, `pbi-desktop`, `reports`, and `semantic-models`

The `.claude/agents/` files should stay focused on role and delegation.
The deeper operating logic belongs here.

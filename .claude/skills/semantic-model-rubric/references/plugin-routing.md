# Plugin routing for semantic-model work

- Use `semantic-models` when the task is an audit, naming review, refresh/model quality review, or lineage-style reasoning.
- Use `pbip` when the user is editing TMDL or PBIR files directly in a project.
- Use `pbi-desktop` when Power BI Desktop is open and you need live DAX or TOM/ADOMD.NET-based inspection.
- Use Microsoft Power BI Modeling MCP only when its semantic-model operations are the better fit than the marketplace plugins.

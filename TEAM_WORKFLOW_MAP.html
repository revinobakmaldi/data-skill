01
Assessment

Project assessment

Combine business scoping, HTML prototyping, and data discovery into one front-loaded stage so the team knows what to build, why it matters, and whether the data can support it.

Team tasks

  • Clarify the business question and decision outcome
  • Define KPI scope, priority, and expected deliverable
  • Build an early HTML prototype of the analytics product
  • Inspect source systems, joins, grain, and data risks
  • Create work items in Azure DevOps for the build

AI leverage

dashboard-wireframe senior-data-engineer persona BigQuery Toolbox — schema discovery Azure DevOps — create work items Stakeholder alignment
Generate HTML prototypes fast with prompts/dashboard-wireframe.md. Explore source schemas without leaving Claude using BigQuery MCP. Create sprint tasks in Azure DevOps directly.
02
Data engineering

Pipeline and ingestion

Move source data into a reliable storage layer with Airflow-managed orchestration, logging, retries, and freshness control.

Team tasks

  • Connect source systems
  • Build extraction and load jobs in Airflow
  • Handle incremental logic and late-arriving data
  • Monitor failures and reruns

AI leverage

dag-builder skill senior-data-engineer persona BigQuery Toolbox — data access Azure DevOps — repo + PR management Airflow scheduling + alerts Prod-readiness check
Generate Airflow DAGs from a pipeline description with skills/dag-builder.md or prompts/dag-scaffold.md. Push code via Azure DevOps MCP and open PRs without leaving Claude.
03
Analytics engineering

Modeling and transformation

Turn raw data into trusted business models, reusable marts, and semantic definitions using dbt-based transformation workflows.

Team tasks

  • Clean and standardize fields in staging layer
  • Define business logic in intermediate layer
  • Create fact and dimension models in dbt
  • Document grain, dependencies, and ownership

AI leverage

dbt-model skill dbt-labs: analytics-engineering altimate-ai: creating-dbt-models altimate-ai: migrating-sql-to-dbt dbt MCP — semantic queries dbt runs + tests Logic validation
Generate staging/intermediate/mart models with schema.yml using skills/dbt-model.md or prompts/dbt-model-generator.md. Use dbt MCP to query the semantic layer. Migrate legacy SQL layer-by-layer with the altimate-ai skill.
04
Quality

Data quality and testing

Make trust visible before anyone consumes the output.

Team tasks

  • Null, duplicate, and integrity checks
  • Reconciliation versus source
  • Threshold and anomaly checks
  • Issue logging and remediation

AI leverage

data-quality-auditor dbt-labs: adding-dbt-unit-test altimate-ai: testing-dbt-models altimate-ai: debugging-dbt-errors dbt-expectations quality gates Root-cause judgment
Generate dbt-expectations or Great Expectations checks from a table profile using prompts/data-quality-checks.md. Debug failures with the altimate-ai debugging skill. Use the community data-quality-auditor for full audits.
05
BI

Analytics product build

Package trusted metrics into the right product form — exploratory reports in Power BI, or self-explanatory HTML reports rendered to PDF.

Team tasks

  • Create measures, hierarchies, and semantic logic
  • Build exploratory report experiences in Power BI
  • Build self-explanatory HTML report products for PDF output
  • Render HTML outputs into polished PDF deliverables
  • Optimize usability, narrative flow, and performance

AI leverage

Power BI MCP — DAX + semantic model insight-writer skill dashboard-wireframe prompts html_to_pdf.py script Business sanity check
DAX generation and semantic model edits via Power BI MCP (mcp/configs/powerbi-mcp.json). Convert any HTML report to PDF automatically with scripts/html_to_pdf.py.
06
Analysis

Exploration and insight generation

Turn trusted data into decision-ready insight — query it, analyze it, and write the narrative that gets acted on.

Team tasks

  • Write and run SQL to answer business questions
  • Analyze datasets for trends and anomalies
  • Generate insights and recommendations
  • Write executive narratives from KPI data

AI leverage

sql-analyst skill insight-writer skill data-analyst skill dbt-labs: NL questions with dbt BigQuery Toolbox — run SQL Analyst fact check
Business question → SQL with skills/sql-analyst.md. Paste data and get analysis with skills/data-analyst.md. KPI table → executive narrative with skills/insight-writer.md. BigQuery MCP runs queries live without copy-paste.
07
Data science

Predictive modeling and experimentation

Build models when descriptive analytics is not enough.

Team tasks

  • Define target and metric
  • Create feature set
  • Train and validate models
  • Explain drivers and tradeoffs

AI leverage

senior-data-scientist persona senior-ml-engineer persona dbt-labs: semantic layer queries BigQuery Toolbox — feature data access Model-risk review
Use skills/community/senior-data-scientist.md and skills/community/senior-ml-engineer.md for notebook scaffolding, feature ideation, experiment design, and model explainability. BigQuery MCP fetches feature data live.
08
Delivery

Deployment and stakeholder delivery

Publish the output safely, explain it clearly, and make it usable.

Team tasks

  • Deploy pipelines and models
  • Publish dashboards or reports
  • Write release notes and documentation
  • Run handoff and stakeholder training

AI leverage

Azure DevOps — PR review + merge Azure DevOps — wiki docs insight-writer — release notes CI / release flow Release approval
Open and merge PRs, write wiki documentation, and update work item states directly via Azure DevOps MCP (skills/azure-devops.md). Generate release notes and stakeholder explainers with skills/insight-writer.md.
09
Operations

Monitoring and iteration

Keep the analytics product healthy after release and prioritize the next improvement.

Team tasks

  • Monitor freshness, usage, and failure
  • Fix incidents and drift
  • Capture stakeholder feedback
  • Prioritize the next improvement

AI leverage

Azure DevOps — work items + queries data-quality-auditor altimate-ai: debugging-dbt-errors Airflow alerts + monitoring Priority judgment
Query open bugs and enhancement requests in Azure DevOps boards via MCP (skills/azure-devops.md). Debug dbt failures with the altimate-ai skill. Use skills/community/data-quality-auditor.md to profile and triage data issues.

# Model Review

## Purpose
Review transformation logic for clarity, trust, and maintainability.

## Expected inputs
- dbt model or SQL
- business logic notes

## Expected outputs
- review findings
- risks
- improvements

## Guidance
- Check grain clarity.
- Check reuse and duplication.
- Check naming and documentation quality.
- Flag silent logic risk before performance nitpicks.

## Starter prompt
Use this skill to handle **model review**. Keep the output practical, concise, and ready for the analytics team to review.

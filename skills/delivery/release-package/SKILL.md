# Release Package

## Purpose
Prepare an analytics output for safe release.

## Expected inputs
- artifact type
- change summary
- target audience

## Expected outputs
- release notes
- validation checklist
- approval summary

## Guidance
- Summarize what changed.
- List validation completed.
- Call out any known limitations.
- Make rollback or fallback obvious.

## Starter prompt
Use this skill to handle **release package**. Keep the output practical, concise, and ready for the analytics team to review.

# Source Onboarding

## Purpose
Standardize onboarding of new data sources into the pipeline layer.

## Expected inputs

- credentials path
- expected tables/endpoints

## Expected outputs
- onboarding checklist
- load plan
- validation steps

## Guidance
- Clarify extraction method.
- Define landing format and partitioning approach.
- State first-load and incremental-load strategy.
- Add validation points before downstream modeling.

# HTML Prototype

## Purpose
Create a fast HTML prototype for an analytics product during assessment.

## Expected inputs
- brief
- KPI list
- target audience
- reference layout if any

## Expected outputs
- HTML prototype concept
- section map
- open UX questions

## Guidance
- Choose the right structure for exploratory or self-explanatory usage.
- Create sections for KPIs, charts, narrative, and actions.
- Optimize for quick stakeholder review, not pixel perfection.
- Call out unknowns before build starts.

## Starter prompt
Use this skill to handle **html prototype**. Keep the output practical, concise, and ready for the analytics team to review.

# PDF Export

## Purpose
Prepare HTML analytics products for reliable PDF rendering.

## Expected inputs
- HTML report structure
- page size or export target

## Expected outputs
- print notes
- layout constraints
- export checklist

## Guidance
- Keep page breaks intentional.
- Preserve readability when printed.
- Protect headline KPIs from bad wrapping.
- Call out browser or renderer-specific risks.

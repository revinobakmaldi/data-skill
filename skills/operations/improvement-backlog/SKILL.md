# Improvement Backlog

## Purpose
Turn repeated issues and feedback into a prioritized improvement backlog.

## Expected inputs
- issue list
- feedback items
- usage signals

## Expected outputs
- clustered backlog
- priority rationale
- recommended owners

## Guidance
- Cluster duplicates.
- Prioritize by business pain and recurrence.
- Separate automation opportunities from one-off fixes.
- Recommend the smallest high-ROI next move.

## Starter prompt
Use this skill to handle **improvement backlog**. Keep the output practical, concise, and ready for the analytics team to review.

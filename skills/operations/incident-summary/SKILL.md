# Incident Summary

## Purpose
Summarize analytics incidents for faster triage and follow-up.

## Expected inputs
- incident details
- logs or symptoms
- affected product

## Expected outputs
- incident summary
- suspected causes
- next actions

## Guidance
- State impact first.
- Separate symptom from suspected root cause.
- Suggest the next investigation step.
- Keep the summary skimmable.

## Starter prompt
Use this skill to handle **incident summary**. Keep the output practical, concise, and ready for the analytics team to review.

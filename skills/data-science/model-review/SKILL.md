# Model Review

## Purpose
Review predictive modeling work for business fit and technical risk.

## Expected inputs
- model summary
- evaluation output
- feature notes

## Expected outputs
- review findings
- deployment risks
- next steps

## Guidance
- Check business usefulness, not just score.
- Ask whether the model is stable and explainable enough.
- Flag training-serving mismatch.
- Recommend the next highest-ROI improvement.

## Starter prompt
Use this skill to handle **model review**. Keep the output practical, concise, and ready for the analytics team to review.

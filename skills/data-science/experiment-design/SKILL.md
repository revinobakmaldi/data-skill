# Experiment Design

## Purpose
Design predictive or experimental work with clear objectives and validation.

## Expected inputs
- target problem
- available data
- evaluation metric

## Expected outputs
- experiment plan
- feature ideas
- risk notes

## Guidance
- Define success before modeling.
- Separate baseline from advanced options.
- Name likely leakage risks.
- Keep the plan executable.

## Starter prompt
Use this skill to handle **experiment design**. Keep the output practical, concise, and ready for the analytics team to review.
